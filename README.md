# MineFlow Central

Crea una aplicación web responsive llamada “MineFlow Alertas”: prototipo visual y funcional con datos mock para una sala de despacho minera. Toda la interfaz debe estar en español. Incluye autenticación demo con roles Administrador, Despachador y Supervisor; dashboard oscuro profesional con hora actual, Turno A, KPIs Camiones activos 23 y Palas en riesgo 5/6; pestañas Alertas, Palas y Camiones; filtros, búsqueda, lista priorizada con las alertas de ejemplo, detalle con timeline, acciones de estado, pantallas de palas/camiones, ajustes con reglas demo, estados vacíos/carga y navegación excelente en escritorio, tablet y móvil. No implementes integraciones externas, GPS, mapas ni control industrial.
